# Make a screen the story writes
When: a screen should fill up during play by itself: an NPC texts {{user}}, a news or social feed reacts to what just happened, rumours spread, a diary writes itself.

1. **Read first.** Read the core API's "Living screens" section (read_doc core-api#living-screens-cf-live) and read_values. Decide where the items go: the screen only, or also into a list value (`into`) so the story sees them. Texts and news the story should remember go into a list (the built-in phone's Phone.Texts, Phone.Feed, Phone.News, or a list of your own made with set_value).
2. **One feed per voice.** A feed is one writer or one outlet: Mina's texts, the Gazette, the town square's gossip. Give it an id the screen reads, a name the player sees in the settings app, and `from` when one person writes it.
3. **Write the content pack.** The pack is all the background call knows besides the last few messages, so make it specific: voice (who writes and how they write: lowercase, emoji, formal), tone (their attitude now), format (the shape of one item: "a text message to {{user}}", "a headline, a dash, one sentence") and length ("one or two short lines"). Use the card's own words for names and places. When the co-writer has written a pack for it, use theirs.
4. **Keep it cheap.** Each run costs about the number read_module shows (`tokens_per_run`): mostly the chat it reads. history 4 to 8, count 1 to 2, and a cadence that fits (texts every 2 or 3 replies or when affection changes; news every 4 or 5, or when the danger value changes). Leave it off (enabled false) unless the user asked for it on, and tell them the cost and how to turn it on (Modules, Living screen) in your summary.
5. **Give it fallback lines.** Two or three lines in the feed's voice for when the call fails, so the screen still moves: "Mina: you up?", "Gazette: Quiet night in the harbour".
6. **Draw it.** In the screen: `app.live(id)` (oldest first), `CF.ui.bubble` or cards for the items, `CF.ui.typing()` while `CF.live.pending(id)`, and redraw on `app.on("live", draw)` and `app.onState(draw)`. Give the empty screen a line of its own ("No texts yet."). A refresh button may call `CF.live.run(id)`, but say on the button that it costs a call. Never call generate yourself for this.
7. **Check it.** Run lint: it says when a screen reads a feed no module has, when a feed follows a value that doesn't exist, has no pack, or is on and read by nothing. Playtest a few replies with the feed on, and swipe once: the items should change with the swipe and come back when you swipe back.
